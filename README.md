# Rush 1 : DataViz Studio — TikTok Performance Analysis

## Contexte & Objectif
Ce projet d'analyse de données est réalisé pour une marque grand public (secteur B2C) préparant sa prochaine campagne d'influence sur TikTok.

L'objectif est d'identifier ce qui distingue objectivement les créateurs et contenus les plus performants, et de livrer à la direction un classeur Excel autonome, rigoureux et synthétique, permettant une prise de décision rapide en moins de 5 minutes.

## Structure du Projet
- `trending_videos.csv` : Données de vidéos tendances scrapées sur la plateforme.
- `trending_authors.csv` : Profils et métriques des créateurs derrière les contenus tendances.
- `tiktok_funny_hashtag_videos.csv` : Échantillon de vidéos associées au hashtag thématique.
- `tiktok_collected_videos.csv` : Vidéos du compte officiel TikTok.
- `tiktok_collected_liked_videos.csv` : Vidéos aimées par le compte officiel TikTok.
- `tiktok_performance_analysis.xlsx` : Classeur d'analyse final livré au format client.

## Méthodologie & Métriques
- **Définition du Succès** : Taux d'engagement normalisé `(Likes + Commentaires + Partages) / Vues` et efficacité par follower.
- **Contrôlable vs Résultat** : Séparation stricte des leviers créatifs (durée, hashtags, audio) des métriques de taille subies.
- **Conformité & RGPD** : Anonymisation des données personnelles sensibles pour le livrable client.
